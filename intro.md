# Miniproyecto Random forest en Pyspark
El presente proyecto tiene como objetivo aplicar técnicas de aprendizaje automático supervisado para predecir el comportamiento de los préstamos emitidos en la plataforma Lending Club.

Se busca clasificar si un préstamo será:

Default (1): el cliente incumple el pago.

Fully Paid (0): el cliente paga el préstamo completamente.

El dataset utilizado contiene más de 1,3 millones de registros con información socioeconómica, financiera y de crédito de los solicitantes, abarcando el periodo 2007–2020.

El análisis y modelado se desarrollará en dos entornos:

scikit-learn (Pandas + ML tradicional)

PySpark (Big Data + MLlib)

Además, se incluirán técnicas de interpretabilidad de modelos con LIME, para comprender mejor las predicciones.
